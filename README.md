# erasure16-spec

Canonical specification and conformance test vectors for **erasure16** — a
systematic Reed–Solomon erasure code over GF(2¹⁶) using a Cauchy generator matrix.
Given `K` data shards it produces `R` parity shards so the data can be rebuilt from
any `K` of the `K + R` shards.

- [`SPEC.md`](SPEC.md) — the normative math/format specification.
- [`vectors/`](vectors/) — conformance test vectors (raw `*.bin` + `MANIFEST.json`),
  generated by `erasure16-dotnet` and verified byte-for-byte by every
  implementation.

## Implementations

Each implementation consumes this repo as a git submodule at
`external/erasure16-spec` and asserts byte-exact conformance against `vectors/`:

- **erasure16-dotnet** — C# / .NET (`netstandard2.0`); also the vector generator.
- **erasure16-java** — Java 11.
